# ADR-101: Deprecate Static API Keys for Short-Lived JWTs

**Status:** Implemented  
**Author:** Bob Smith (Security Architect, SecOps)  
**Date:** 2025-03-12  
**Affected Services:** auth-service

## Rationale
Static API keys have unlimited lifetime and are difficult to revoke individually. Moving to JWT with 15-minute rotation reduces blast radius and enables fine-grained revocation per session.

## Implementation
- All internal clients must use `Authorization: Bearer <jwt>`.
- Token rotation is automatic via `auth-service` sidecar.
- Deprecated keys removed from `user-db` secret store on 2025-03-15.
